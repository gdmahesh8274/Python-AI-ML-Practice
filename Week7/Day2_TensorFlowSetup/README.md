# TensorFlow Setup

Install the packages used in Week 7 Day 2:

```bash
python -m pip install tensorflow scikit-learn matplotlib numpy
```

Check the installation:

```bash
python Week7/Day2_TensorFlowSetup/main.py
```

Then run the other Day 2 `main.py` files individually. The loss/accuracy plotting script saves two PNG charts in its folder when executed. TensorFlow may take a moment to start, and CPU training is fine for these small examples.
