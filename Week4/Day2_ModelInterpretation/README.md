# Week 4 - Day 2 - Model Interpretation

## Coefficient

The coefficient shows how much the predicted target changes when the input feature increases by one unit.

For the study-hours example, a positive coefficient means predicted marks increase as study hours increase.

## Predictions

A prediction is the value generated by the trained regression model for an input.

The model learns the relationship between study hours and marks from the training data and uses that relationship to predict marks.

## Model Behavior

Linear regression fits a straight line through the data.

If the actual values are close to the predicted values, the model has smaller errors.

MAE shows the average absolute prediction error. MSE also measures prediction error but gives larger errors more weight.
