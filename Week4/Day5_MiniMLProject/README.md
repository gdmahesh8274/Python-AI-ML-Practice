# Week 4 Day 5 - Mini ML Project

## Objective

Build a simple machine learning classification project using the Iris dataset.

## Steps

1. Load the Iris dataset.
2. Separate features and target.
3. Split data into training and testing sets.
4. Scale the feature values with StandardScaler.
5. Train Logistic Regression and KNN models.
6. Make predictions.
7. Compare model accuracy.
8. Display a confusion matrix and classification report.

## Run

```bash
python main.py
```
