# Week 2 NumPy and Pandas Summary

## NumPy

This week I practiced:

- Creating 1D and 2D arrays
- Checking shape, size, and dimensions
- Array indexing and slicing
- Array addition, subtraction, multiplication, and division
- Reshaping and flattening arrays
- Creating random integer and float arrays
- Mean, median, and standard deviation
- Matrix addition and multiplication

## Pandas

This week I practiced:

- Creating Pandas Series
- Series indexing and filtering
- Creating DataFrames from dictionaries and lists
- Reading CSV files
- Using head(), tail(), info(), and describe()
- Selecting single and multiple columns
- Filtering rows with conditions
- Finding, filling, and dropping missing values
- Renaming columns and sorting values
- Creating calculated columns
- Using groupby() for counts and averages

## Mini Project

I created a small student marks dataset, handled a missing value, calculated total and average marks, grouped results by department, and found the student with the highest average.
