# Mini EDA Project

## Objective

Explore a small student dataset and identify useful patterns using Pandas and Matplotlib.

## Dataset

The dataset contains student name, department, study hours, attendance, and marks.

## Cleaning and Inspection

- Loaded the CSV file with Pandas.
- Inspected the first rows and dataset information.
- Checked descriptive statistics.
- Checked for missing values.
- Grouped marks by department.

## Charts

The Python script creates:

1. Student marks bar chart
2. Study hours vs marks scatter plot
3. Marks distribution histogram

## Key Findings

1. Sara has the highest marks.
2. Alex has the lowest marks.
3. Higher study hours are associated with higher marks in this sample.
4. IT has the highest average marks in this sample.
5. The dataset contains no missing values.

Run `main.py` to generate the PNG chart files.
