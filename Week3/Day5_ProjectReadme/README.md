# Week 3 EDA Project Documentation

## Dataset Objective

The objective is to explore student performance and understand relationships between study hours, attendance, department, and marks.

## Cleaning Steps

- Load the CSV dataset with Pandas.
- Inspect rows, columns, and data types.
- Check for missing values.
- Review descriptive statistics.
- Group marks by department.

## Charts

- Bar chart for student marks
- Scatter plot for study hours and marks
- Histogram for marks distribution

## Key Findings

1. Sara has the highest marks.
2. Alex has the lowest marks.
3. Students with more study hours generally have higher marks in this sample.
4. IT has the highest average marks in this sample.
5. The sample dataset has no missing values.

The charts are generated by the script in `Week3/Day5_MiniEDAProject`.
