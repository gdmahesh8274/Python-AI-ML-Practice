# Week 5 Day 5 - Student Performance Prediction

This beginner-friendly machine learning project predicts whether a student passes based on study hours and attendance.

## Files

- `students.csv`: sample student data
- `main.py`: data inspection, training, evaluation, and prediction

## How to run

Install dependencies with `pip install pandas scikit-learn`, then run `python main.py` from this folder.

The program prints accuracy, a confusion matrix, a classification report, and a prediction for a new student.

This is a small educational sample dataset, not a real-world prediction system.
